## 📌 Standar Penulisan Kode

- **Fitur Bawaan Python**: Mengutamakan struktur data bawaan (`list`, `dict`, `tuple`, `set`) tanpa ketergantungan pustaka eksternal.
- **Anotasi Logika**: Penjelasan singkat cara kerja algoritma pada blok kontrol dan struktur data kunci (`# penjelasan: ...`).
- **Analisis Algoritma**: Memperhatikan efisiensi *Time Complexity* dan *Space Complexity* pada setiap solusi.
